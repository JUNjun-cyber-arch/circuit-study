2. 磁滞、剩磁与矫顽力

先看懂，再记公式

这一小节在讲什么？

把材料先磁化到正向，再把励磁减小。B 的变化路线不会原样返回，材料的磁化状态与前面怎样励磁有关。

1沿着回线走
2H = 0 时读剩磁
3B = 0 时读反向 H

教材对应：教材 §1.3，印刷页 19–21，图 1.9。

从正向磁化的回线分支撤去励磁，H = 0 时残留的 B 叫剩磁 Br。继续反向励磁，到 B = 0 时所需反向 H 的幅值是矫顽力 Hc。不同回线和测量条件会影响读到的数值。

软磁材料一般容易反复磁化，适合许多交流铁芯。永磁材料需要在工作条件下维持磁化状态，选材还要看材料的退磁特性。

从正向磁化分支把 H 降到零，读出的 B 叫什么？

  1. 矫顽力
  2. 磁阻
  3. 剩磁
参考答案与提示

答案：剩磁

剩磁是 H = 0 时留下的 B。矫顽力是使 B 回到零所需的反向 H 幅值。

提示：先判断是在横轴还是纵轴找截距。

4. 预习铁损，区分磁滞与涡流

先看懂，再记公式

这一小节在讲什么？

交变磁场下，铁芯会反复磁化。磁滞造成每周期的能量损耗；交变磁通还会在导电铁芯内部感应出涡流并发热。

1先辨认交变磁通
2区分磁滞与涡流
3看材料和结构怎样减小损耗

教材对应：教材 §1.4，印刷页 25–27，铁损部分预习。

在给定的磁滞回线下，每周期单位体积的磁滞损耗由回线面积表征。薄且相互绝缘的叠片可限制涡流回路，从而减小涡流损耗。线圈绕组因电阻产生的损耗通常单独计为铜损。

实际损耗随材料、频率、波形和磁通密度等条件变化。本讲只建立区别，计算会在交流励磁部分继续。
